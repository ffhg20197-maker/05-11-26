ОСНОВНЫЕ ПОНЯТИЯ

DevOps объединяет
разработку и эксплуатацию.

CI автоматически проверяет изменения кода в общем репозитории. CD подготавливает проверенную версию к выпуску или автоматически развёртывает её в рабочей среде.

ЖИЗНЕННЫЙ ЦИКЛ

Восемь этапов
публикации

Каждый шаг делает выпуск предсказуемее. Отмечайте этапы по мере изучения.

01

Разработка

Создание HTML-, CSS-, JavaScript-файлов и серверной части.

02

Контроль версий

Фиксация изменений с помощью Git и отправка кода в GitHub.

03

Проверка CI

Получение исходного кода, установка среды и зависимостей.

04

Качество и тесты

Линтинг, статический анализ и автоматическое тестирование.

05

Сборка

Подготовка готовой версии приложения и сохранение артефакта.

06

Подготовка

Проверка настроек, секретов, зависимостей и целевой среды.

07

Развертывание

Передача проверенной версии на сервер или GitHub Pages.

08

Проверка сайта

Тестирование страниц, ссылок, ресурсов и мобильного отображения.

АВТОМАТИЗАЦИЯ

Что происходит
после push?

  1. GitHub получает измененияСрабатывает событие push или pull_request.
  2. Runner запускает workflowactions/checkout получает исходный код.
  3. CI проверяет проектПроверяется наличие index.html, style.css и script.js.
  4. CD публикует сайтПри успешной проверке файлы передаются в GitHub Pages.
